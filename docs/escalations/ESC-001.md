# ESC-001: Confirm three gate and compose choices made in M1
Status: open
Trigger: 1 (spec conflict) and 2 (gate contents)
Milestone / gate / AC: M1 / gate 14, docker-compose / AC-OPS-1, all ACs
Raised: 2026-10-04T11:59:05Z at commit 42ba3f6

## What happened

The M1 audit (spec-auditor) found three choices that touch a gate or contradict an exact
spec sentence. Each one is needed to make the build work. They are batched here (12.5 step 7).
Work continues with the current behaviour; nothing is blocked.

1. **Gate 14 before M8 (D-003).** Spec 11.3: gate 14 is active from M1 and fails when "any
   acceptance criterion" has no passing test. Most ACs can only get tests in later milestones
   (12.2). Current behaviour: each ID has a due milestone; a missing test fails from that
   milestone and shows as `pending` before it. Unknown IDs and failing tagged tests always
   fail. From M8 every ID is required.
2. **ERR ID format (D-004).** Spec 11.4 gives the form `ERR-<METHOD>-<path>-<status>` but no
   path style and no list. Current: path relative to `/api/v1` (`ERR-POST-/admin/groups-409`),
   the list in `scripts/lib/trace-registry.mjs` (6.1 Errors column plus login, token and
   evaluation endpoints), and each 9.1 row mapped to one ERR ID.
3. **Compose `FF_DB_URL` default (D-001).** Spec 10.3: compose passes every 9.4 variable as
   `${VAR:-<default from 9.4>}`. The 9.4 default for `FF_DB_URL` is `localhost:5432`, which
   inside the backend container is the container itself, so `make up` (AC-OPS-1) would fail.
   Current: `${FF_DB_URL:-jdbc:postgresql://postgres:5432/featureflags}`.

## Evidence

M1 audit findings SA-3, SA-5, SA-6. `make verify` is green with the current behaviour.

## What was tried

For item 3: with the literal 9.4 default the backend cannot reach the database in compose.
Sharing the postgres network namespace (`network_mode: service:postgres`) would make
`localhost` work, but then the `backend` host name used by the UI (`BACKEND_URL`) no longer
resolves, and ports move to the postgres service.

## Options

A. Keep all three as they are now (recommended). Gate 14 at M8 is exactly spec 11.4; before
   M8 it still blocks unknown IDs, failing tests and overdue IDs.
B. Keep 2 and 3; make gate 14 require every AC from M1 (every milestone before M8 then stays red,
   and no milestone can be completed).
C. Other: tell me which item to change and how.

## Recommendation

A.
