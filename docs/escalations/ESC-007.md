# ESC-007: Final review — three startup and API decisions made at Level 1

## What happened

The final review (spec-auditor SA-3, SA-6, SA-7; java-reviewer JR-3) found three choices I made
at Level 1 that touch configuration, a security rule or the API.

1. **TTL with fractions of a second (SA-3).** 5.1: "Any ISO-8601 duration of 1 second or more is
   accepted". 5.2: "`iat` and `exp` are integer seconds", "`exp - iat` equals the token TTL in
   seconds". For `PT1.5S` both cannot be true. Today startup fails for such a TTL (D-019).
2. **Extra startup failures (SA-6).** Startup also fails for a blank admin password or a blank
   client secret (D-019). 5.1 lists only a short `jwt-secret` and duplicate client ids.
3. **Small API details (SA-7).** `Cache-Control: no-store` on the login response (D-018), and
   `If-None-Match` also accepts a weak tag (`W/"42"`) and a list (`"41", "42"`) (D-023).

## Options

A. Item 1: accept a TTL with fractions; tokens use the whole seconds (floor), and the floored TTL
   must still be 1 s or more. Items 2 and 3: keep as built (recommended).
B. Keep everything as built (item 1 keeps failing startup).
C. Other (say which item changes).

## Recommendation

A. Item 1 then follows "accepted" in 5.1 and keeps integer `iat`/`exp`. Items 2 and 3 only
reject configurations that cannot work and follow RFC 9110 / RFC 6749 practice.

## Blocked meanwhile / continuing with

Not blocking other work. Item 1 stays as built until the answer.

## Question (one, answerable with an option letter)

Accept A, or B / C?

## Answer (filled in when resolved)

Owner, 2026-10-05 (PR comment 5992802206): **A**.
1. A TTL with fractions of a second is accepted (5.1). Tokens use whole seconds (floor); the
   floored TTL must be 1 s or more, otherwise startup fails. `iat`/`exp` stay integers and
   `exp - iat` equals the floored TTL (5.2).
2. Keep the startup failures for a blank admin password or client secret (D-019).
3. Keep `Cache-Control: no-store` on login (D-018) and weak / list `If-None-Match` (D-023).
Applied in D-039.
