# ESC-003: NimbusJwtEncoder cannot write `aud` as a one-element array
Status: resolved
Trigger: 1 (spec conflict: 5.1 vs 5.2)
Milestone / gate / AC: M3 / gate 5 / AC-EVAL-1 (token claims)
Raised: 2026-10-04T13:02:19Z at commit 09ce8fe

## What happened

Spec 5.1: tokens are "issued with Spring Security's `NimbusJwtEncoder`". Spec 5.2: "`aud` is an
array with one string". `NimbusJwtEncoder` passes the audience to Nimbus `JWTClaimsSet`, and
Nimbus (10.5, used by Spring Security 6.5) always writes a one-element audience as a plain string
(`"aud":"feature-flag-admin"`). There is no setting to change this.

## Evidence

`TokenIssuerTest.claimsAreEncodedWithTheSpecJsonTypes` failed with NimbusJwtEncoder:
payload `{"iss":"feature-flag-service","sub":"admin","aud":"feature-flag-admin",...}`.
Nimbus `JWTClaimsSet.toJSONObject`: `if (audList.size() == 1) put("aud", audList.get(0))`.

## What was tried

1. `NimbusJwtEncoder` with `JwtClaimsSet.audience(List.of(aud))`: string.
2. Checked `NimbusJwtEncoder` and Nimbus `JWTClaimsSet` for an option: none.

## Options

A. Keep a small Spring Security `JwtEncoder` implementation (`HmacJwtEncoder`) that signs with
   Nimbus (`MACSigner`) and writes `aud` as an array (5.2 holds; tokens are still signed by
   Nimbus and validated by `NimbusJwtDecoder`; `TokenIssuer` still wraps a `JwtEncoder`). In place now.
B. Use `NimbusJwtEncoder` as 5.1 says; `aud` becomes a string (5.2 broken; the black-box suite may
   check the array).
C. Other.

## Recommendation

A. 5.2 is the exact, testable contract; A changes nothing else.

## Blocked meanwhile / continuing with

Not blocking. Option A is in `auth/HmacJwtEncoder.java` (one class); switching to B is a one-line change.

## Question (one, answerable with an option letter)

Accept A, or B / C?

## Answer (filled in when resolved)

Owner, 2026-10-04 (PR comment, answer to 5980411426): **A**.
Keep `HmacJwtEncoder` (signs with Nimbus `MACSigner`, writes `aud` as a one-element array).
Spec 5.2 wins over the encoder class named in 5.1. Recorded in D-040. No code change.
